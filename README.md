# dz2
## Описание:
Приложение реализует аналогичный интерфейс профиля пользователя, как и с библиотекой **pyqt6**, но с использованием стандартной библиотеки **Tkinter**, входящей в состав Python.  
Служит для демонстрации базовых принципов построения окон и виджетов без сторонних фреймворков.


## Технологический стек:
Компонент - Версия - Назначение
**Python** - 3.9+ - язык разработки 
**Tkinter** - стандартная библиотека | фреймворк для создания GUI 
**PhotoImage, Label** | встроенные классы | отображение изображений и текста 


## Требования:
- Python **3.9 или выше**
